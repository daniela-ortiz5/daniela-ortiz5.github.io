Data Visualization

Type — Maps & Charts Tools — Datawrapper, QGIS Focus — Reporting-driven data Section — 03 · Pg. 03b

A collection of maps created with Datawrapper and QGIS for reporting projects. These projects use statistics and structured information to make reporting easier to understand.

Chart · Datawrapper

A choropleth map showing canopy coverage loss in Alachua County, Florida, built using a combination of Datawrapper and QGIS. Created for an upcoming WUFT story about tree loss in the county.

Map · Datawrapper

A locator map showing selected running routes in Gainesville, Florida, based on reporter-collected data. The lines were drawn using GeoJSON.

Chart · Datawrapper

A choropleth map showing opt-in to the K-12 school guardian program by county in Florida. Used in my WUFT-published story about the school guardian program.
